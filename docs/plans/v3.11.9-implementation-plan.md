# Pear Desktop v3.11.9 Implementation Plan: Feature Porting & Security Remediation

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port safe, high-value modular features from `michei69/pear-desktop` (v3.12.0...v3.13.0-beta.173) into v3.11.9 without breaking existing functionality, and remediate all open Dependabot security advisories on `alsyundawy/pear-desktop-mac`.

**Architecture:** Maintain strict backwards compatibility on the Electron 42.x runtime. Cherry-pick and port self-contained plugins (UI, content filtering, and playback controls), upgrade Synced-Lyrics providers and resilience, adopt Ears-style 11-band parametric equalizer, and implement transitive dependency overrides (`pnpm.overrides`) alongside direct package bumps to clear all security alerts.

**Tech Stack:** TypeScript 5.9+, Electron 42.11.16, Vite 7/8 (Rolldown/ESBuild), SolidJS, Hono 4.13.13, Zod 4.6.6, pnpm 10+.

**Spec Reference:** Git compare `michei69/pear-desktop` (`v3.12.0...v3.13.0-beta.173`) & GitHub Dependabot alerts on `alsyundawy/pear-desktop-mac`.

---

## Global Constraints

- **Electron Runtime Floor:** Do NOT upgrade to Electron 45 in v3.11.9 (retains macOS 11/12 compatibility and prevents breaking native node-smtc addons). Bump within the 42.x line to `42.11.16` to patch all known CVEs.
- **Architectural Isolation:** All new features must be implemented as modular, toggleable plugins in `src/plugins/<plugin-name>/` with independent teardown lifecycles (`stop()`, event cleanup, and DOM unmounts).
- **Zero Regression Bar:** Existing configurations (`config.json`), player hooks, and audio graphs must maintain complete fallback compatibility.
- **Shell & Toolchain Compliance:** macOS x86_64 login shell `/usr/local/bin/bash -l`, node v24+, pnpm 10+.
- **Verification Gate:** Zero TypeScript errors (`pnpm typecheck`), zero ESLint errors (`pnpm lint`), and clean security audit before merging.

---

## Review Focus

1. **Audio Graph Stability:** When enabling the new 11-band equalizer or audio-compressor, verify that disconnecting and reconnecting Web Audio nodes does not silence podcast/stream playback or trigger memory leaks.
2. **DOM Observer Teardown:** Ensure DOM mutation observers (`fullscreen-auto-hide`, `dismiss-multidevice-popup`, `toast-autoclose`) cleanly disconnect on plugin disable or window navigation.
3. **Player Bar Cascade Override:** Verify that `always-show-volume-slider` styles override YouTube Music's native pointer-events and opacity without obstructing neighbouring player controls.
4. **Input Guarding for Keystrokes:** Confirm `seek-shortcuts` never intercepts arrow keys when the user is typing in search inputs, comments, or modal dialogues.
5. **Transitive Dependency Resolution:** Ensure `pnpm.overrides` forces patched versions (`seroval`, `minimatch`, `undici`, `fast-uri`, `ip-address`) without breaking build plugins (`vite-plugin-solid`, `electron-vite`).
